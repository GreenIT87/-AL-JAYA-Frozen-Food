4 Langkah Mudah Pasang Google Sheets:

  1. Buka Spreadsheet baru di sheets.new.
  2. Klik menu Ekstensi > Apps Script, lalu hapus kode lama dan klik tombol Salin Apps Script di sebelah kiri.
  3. Klik tombol biru Terapkan > Deployment baru, pilih jenis Aplikasi Web, ubah Akses ke: Siapa saja (Anyone).
  4. Salin URL Web App berakhiran /exec ke kolom di kiri, lalu klik Simpan & Sync.

Printer AT-58X / Generic Bluetooth 58mm

Panduan Pairing Printer AT-58X:

1. Nyalakan printer AT-58X hingga lampu indikator LED biru/hijau menyala stabil.

2. Pastikan Bluetooth di HP / Komputer aktif, lalu pair perangkat AT-58X atau POS-58.

3. Jika diminta PIN pairing, masukkan: 1234 atau 0000.

4. Klik tombol "Hubungkan Bluetooth AT-58X" di bawah.

Panduan Lengkap Sinkronisasi Google Sheets

Hubungkan toko ²AL JAYA dengan Google Sheets secara langsung

1
Buat Dokumen Spreadsheet Baru

Buka link Google Spreadsheet berikut di tab baru:

Klik di sini: sheets.new
2
Buka Menu Ekstensi > Apps Script

Pada Google Sheet Anda, klik menu atas Ekstensi (Extensions) lalu pilih Apps Script.

3
Hapus Kode Bawaan & Tempel Kode Script Berikut

Hapus teks myFunction() lalu klik tombol salin di bawah:

// GOOGLE APPS SCRIPT BACKEND ²AL JAYA FROZEN FOOD POS
function getOrCreateSheet(ss, name, headers) { ... }
function doGet(e) { ... }
function doPost(e) { ... }
4
Deploy sebagai Aplikasi Web (Web App)

Di Apps Script, klik tombol biru Terapkan (Deploy) > Deployment baru (New deployment):

  • Pilih jenis roda gigi: Aplikasi Web (Web App)
  • Deskripsi: Backend POS AL JAYA
  • Jalankan sebagai: Saya (Me)
  • Siapa yang memiliki akses: Siapa saja (Anyone) (Wajib agar bisa diakses aplikasi)
5
Salin URL Web App & Tempel di Aplikasi

Salin URL yang berakhiran /exec lalu tempel di kolom input Google Sheets di aplikasi ini.
